# FinTech Document Intelligence Agent

A production-oriented GenAI system that answers questions over
financial documents using RAG and a LangGraph agent.

## Planned Architecture

PDFs
→ Document Ingestion
→ Chunking
→ Embeddings
→ FAISS
→ RAG
→ LangGraph Agent
→ LLM
→ Answer + Sources

## Tech Stack

- Python
- LangChain
- LangGraph
- Hugging Face / Sentence Transformers
- FAISS
- FastAPI
- Streamlit
- Docker
